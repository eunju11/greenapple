카카오톡 회원가입 연동 키(API Key) 설정 안내

실제 카카오톡 인증 화면으로 연결하기 위해 환경 변수 등록이 필요합니다.

현재 프로젝트에 KAKAO_CLIENT_ID 환경 변수가 설정되어 있지 않습니다.
💡 카카오 로그인 3단계 설정 방법
  1. 카카오 디벨로퍼스(Kakao Developers) 앱 생성
    developers.kakao.com에 로그인 후 [내 애플리케이션] > [애플리케이션 추가하기]를 진행합니다.
  2. 카카오 로그인 활성화 & Redirect URI 등록
    [제품 설정] > [카카오 로그인] 메뉴에서 활성화 토글을 ON으로 변경하고, 아래 Redirect URI를 추가합니다.
    {{ redirect_uri }}
  3. .env 파일에 REST API 키 입력
    [앱 설정] > [앱 키]에서 REST API 키를 복사하여 프로젝트 최상위의 .env 파일에 추가합니다.
# .env 파일에 아래 내용을 추가하세요
KAKAO_CLIENT_ID=여러분의_카카오_REST_API_키
KAKAO_REDIRECT_URI={{ redirect_uri }}
